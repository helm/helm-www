Ce document décrit le décalage de version maximal pris en charge entre Helm 4 et
Kubernetes.

## Versions prises en charge {/* #supported-versions */}

Les versions de Helm sont exprimées sous la forme `x.y.z`, où `x` est la version
majeure, `y` la version mineure et `z` la version de correctif, selon la
terminologie du [versionnage sémantique](https://semver.org/spec/v2.0.0.html).

Le projet Helm maintient une branche de release pour la version mineure la plus
récente. Les correctifs applicables, y compris les correctifs de sécurité, sont
reportés (cherry-pick) dans cette branche, selon leur gravité et leur faisabilité.
Plus de détails sont disponibles dans la
[politique de publication de Helm](/community/release_policy).

## Décalage de version pris en charge {/* #supported-version-skew */}

Lorsqu'une nouvelle version de Helm est publiée, elle est compilée avec une
version mineure donnée de Kubernetes. Par exemple, Helm v4.0.0 interagit avec
Kubernetes au moyen du client Kubernetes 1.34.1 : il est donc compatible avec
Kubernetes 1.34.

À partir de Helm 4, Helm est considéré comme compatible jusqu'à la version `n-3`
de Kubernetes, `n` étant la version avec laquelle il a été compilé.

Par exemple, si vous utilisez une version de Helm 4 compilée avec les API du
client Kubernetes v1.35, vous devriez pouvoir l'utiliser sans risque avec
Kubernetes v1.35, v1.34, v1.33 et v1.32.

Il n'est pas recommandé d'utiliser Helm avec une version de Kubernetes plus
récente que celle avec laquelle il a été compilé, car Helm ne garantit pas la
compatibilité avec les versions futures.

Si vous choisissez d'utiliser Helm avec une version de Kubernetes qu'il ne prend
pas en charge, c'est à vos risques et périls.

Consultez le tableau ci-dessous pour savoir quelle version de Helm est compatible
avec votre cluster.

| Version de Helm | Versions de Kubernetes prises en charge |
|-----------------|-----------------------------------------|
| 4.3.x           | 1.37.x - 1.34.x                         |
| 4.2.x           | 1.36.x - 1.33.x                         |
| 4.1.x           | 1.35.x - 1.32.x                         |
| 4.0.x           | 1.34.x - 1.31.x                         |
