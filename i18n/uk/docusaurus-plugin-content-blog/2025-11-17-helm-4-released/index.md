У середу, 12 листопада, під час [презентації Helm 4 на KubeCon + CloudNativeCon](https://sched.co/27Nme) було випущено [Helm v4.0.0](https://github.com/helm/helm/releases/tag/v4.0.0). Це перша нова основна версія Helm за 6 років. <!-- truncate -->

## Що нового {#whats-new}

Helm v3 добре слугував спільноті Kubernetes протягом багатьох років. За цей час ми бачили нові способи використання Helm, нові застосунки, встановлені за допомогою чартів, зростання [Artifact Hub](https://artifacthub.io/) та численні інструменти, що будуються на основі Helm. Ми також бачили, де хотіли додати функції, але внутрішня архітектура Helm не надавала шляху вперед без порушення публічних API в SDK. Helm 4 вносить ці зміни, щоб забезпечити нові функції зараз і в майбутньому.

Деякі з нових функцій включають:

- Перероблена система втулків, що підтримує втулки на основі Web Assembly
- Post-renderers тепер є втулками
- Тепер підтримується застосування на стороні сервера (server-side apply)
- Покращене відстеження ресурсів для підтримки очікування на основі kstatus
- Локальне кешування на основі вмісту (наприклад, для чартів)
- Логування через slog, що дозволяє інтегрувати логування SDK з сучасними логерами
- Відтворювані/ідемпотентні збірки архівів чартів
- Оновлений SDK API, включаючи підтримку кількох версій API чартів (нова експериментальна версія API чартів v3 з'явиться найближчим часом)

Детальніше про зміни можна дізнатися в [Огляді Helm 4](/docs/overview).

## Підтримка Helm v3 {#helm-v3-support}

Коли виходить нова основна версія програмного забезпечення, потрібен час для переходу. Підтримка Helm v3 буде продовжуватися, щоб забезпечити плавний перехід. Дати продовженої підтримки такі:

- Виправлення помилок до 8 липня 2026 року.
- Виправлення безпеки до 11 листопада 2026 року.

Helm випускає оновлення по середах (зазвичай 2-а середа місяця), і ці дати відповідають датам випуску. Протягом цього часу **_НЕ_** будуть перенесені нові функції, окрім оновлень клієнтських бібліотек Kubernetes, які забезпечують підтримку нових версій Kubernetes.

## Дізнатися більше {#learn-more}

Ви можете дізнатися про зміни в Helm у [Огляді](/docs/overview) або знайти всі зміни в [повному журналі змін](/docs/changelog). Документація містить набагато більше деталей, оскільки ви можете знайти всі способи, якими Helm залишався незмінним, та нові функції, якими ви можете скористатися.
